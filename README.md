# Minecraft Clone

A voxel-based 3D sandbox game built with **TypeScript + Vite + THREE.js**. All graphics assets (textures, sky, lighting) are procedurally generated in code — no external binary resource files are required.

## Features

- **Procedural terrain generation**: Multi-octave fractional Brownian motion (FBM) based on Simplex noise — every world entry generates brand-new terrain (plains, hills, mountains, water)
- **First-person controls**: Pointer Lock mouse look + WASD movement + space to jump, with gravity and collision system (0.6×1.8×0.6 block collision volume)
- **Block interaction**: Left-click to break (with crack animation and particle effects), right-click to place; a translucent wireframe highlight appears over the targeted block
- **9-slot hotbar**: Grass, Dirt, Stone, Sand, Wood, Leaves, Water, Bedrock, Glass; switch with number keys 1-9
- **Day/night cycle**: A complete 10-minute cycle with sky gradients, sun/moon lighting, and fog color that synchronizes with the sky
- **Full menu flow**: Main menu / loading screen (with progress bar) / pause menu / controls screen / about screen
- **Pure procedural visuals**: 16×16 CanvasTexture pixel-art textures, gradient sky dome, particle system, and smooth camera transitions

## Tech Stack

- [TypeScript](https://www.typescriptlang.org/) — strict-mode type checking
- [Vite](https://vitejs.dev/) — development server and build tooling
- [THREE.js](https://threejs.org/) — 3D rendering engine
- Voxel technology — chunk-based block world storage and merged-mesh rendering

## Getting Started

## Game Mechanics

### Block Types

| Block | Description |
|-------|-------------|
| Grass | Green top, brown side with green stripe |
| Dirt | Uniform brown texture |
| Stone | Gray granular texture |
| Sand | Light yellow granular texture |
| Wood | Brown vertical stripes (bark texture) |
| Leaves | Semi-transparent green texture |
| Water | Blue, semi-transparent, walkable (50% move speed) |
| Bedrock | Dark gray, indestructible (world floor) |
| Glass | Transparent, see-through |

### World Specification

- Map size: **512×512 blocks** (X × Z), with a height of 128 layers
- Chunks: 16×16×16 blocks; the world consists of 32×32×8 chunks
- World bounds: X / Z coordinates span [-256, 255], Y coordinates [0, 127] (y=0 is the bedrock layer)
- Trees generate randomly on grass surfaces; water bodies form in low-lying areas

### Day/Night Cycle

- Full cycle: 10 minutes (600 seconds)
- Day → dusk → night → dawn, with smooth sky color and light intensity transitions
- The world darkens at night but retains dim moonlight for visibility

## Scope

**In scope (v1)**: Single-player creative mode, procedural terrain, block break/place, hotbar, day/night cycle, first-person controls, basic physics, procedural textures, and full menu flow.

**Out of scope (explicitly excluded)**: Multiplayer, redstone circuits, mobs/AI, crafting, hunger/health, audio/music, Mod support, save/load, inventory system, and binary asset files.
